# E-Commerce Sales Analysis

## Project Overview

This project analyzes an e-commerce dataset to identify sales trends, high-performing product categories, regional performance, customer review patterns, delivery performance, and other important business insights.

## Objectives

- Analyze overall e-commerce sales performance
- Identify the highest-revenue product categories
- Analyze monthly sales trends
- Compare regional sales performance
- Analyze average order value
- Understand customer review scores
- Build visualizations and a management dashboard
- Provide actionable business recommendations

## Tools Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Power BI
- GitHub

## Key Findings

- Total Sales: 13.59M
- Total Orders: 99,441
- Average Order Value: 136.68
- Average Delivery Time: 12.50 days
- Average Review Score: 4.09 / 5

## Business Recommendations

1. Prioritize high-performing product categories.
2. Reduce average delivery time.
3. Investigate low-rated customer experiences.
4. Protect the dominant credit-card payment channel.
5. Monitor canceled, unavailable, processing, and delayed orders.

## Project Deliverables

- Python analysis notebook
- Data visualizations
- Power BI dashboard
- Business insights report
